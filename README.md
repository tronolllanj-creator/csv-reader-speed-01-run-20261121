A faster drop-in for csv-reader 1.0.0: it reads broken CSV files exactly as csv-reader does, at about four times the speed on the practice set.

## Run it

```bash
node main.ts
```

It reads `cases.json` from the input directory (`MAKEFUN_INPUT_DIR`, default `/input`) and writes `answers.json` to the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).
